### <h1>Counter App</h1>

A simple counter application built using React that allows users to increment, decrement, and reset the counter value.

<h2>Features</h2>
<ul>
  <li>Increment the counter value by clicking the + button.</li>
  <li>Decrement the counter value by clicking the - button.</li>
  <li>Reset the counter value to zero using the Reset button.</li>
</ul>

<h2>Technologies Used</h2>
<ul>
  <li>React.js</li>
</ul>

## Installation
<ol>
  <li>Clone the repository: <b>git clone https://github.com/snasreen001/REACT-COUNTER-APP.git</b></li>
  <li>Navigate to the project folder: <b>cd REACT-COUNTER-APP</b></li>
  <li>Install dependencies: <b>npm start</b></li>
  <li>Start the development server: <b>npm start</b></li>
</ol>

## Usage
<ol>
  <li>Open the app in your browser at <b>http://localhost:3000</b></li>
  <li>Click <b>+</b> to increase the counter value.</li>
  <li>Click <b>-</b> to decrease the counter value.</li>
  <li>Click <b>Reset</b> to reset the counter to zero.</li>
</ol>
